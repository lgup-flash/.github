# LGUP - Flash an LG Package in Download Mode

## At a Glance

LG's desktop flasher depends on model support being installed. Without the DLL for this series, the phone may appear and still refuse the file. With the right support, you select a KDZ and a mode the package allows, then you wait. Refurbish and upgrade modes are not interchangeable. Read which one this file expects before you start.

- Download mode and an LG USB driver
- Model support that matches the phone
- A KDZ for this model, not a neighboring one
- A full battery
- User data treated as lost unless the chosen mode truly keeps it

1. Install the driver and the model DLL.
2. Enter download mode and confirm LGUP sees the phone.
3. Load the KDZ and read the model it reports.
4. Choose the mode the file's note describes.
5. Start and do not disconnect.
6. Boot and check the software version.

## Fits

LG phones you may reflash with an official package. A poor fit for Pixel, Samsung, or a generic Android box. A poor fit if the DLL for this model is not installed. A poor fit for recovering photos. Copy them before a refurbish flash.

## Fixes

The phone is detected and the file is rejected. The DLL or the model is wrong.
The flash stops early. Another port, same KDZ.
The phone boot-loops. Do not try a KDZ from a different variant. Repeat the correct file or use the backup you have.
You picked a wipe mode by habit. Data is gone. That was the mode, not a bug.
LGUP will not install. The PC build may be newer than the tool. Use a setup the DLL actually supports.

## DLL, Model, Then the KDZ

LGUP can see a phone and still reject the file when the model DLL is missing or belongs to another series. Install the driver and the support for this model before you enter download mode. Load the KDZ and read the model it reports. If that string is not the phone in your hand, unload it. Refurbish and upgrade are different modes. The one that wipes data will wipe data. Copy photos first if the mode you must use does not keep them.

A neighboring KDZ is not a small regional language pack. Repeat the correct file if the flash stops. Do not browse other models because the progress bar froze. Use a USB port that stays awake, and a Windows setup the DLL still supports. A tool that will not install on a new Windows build is a PC problem, not a dead phone.

- Driver and model DLL installed first
- KDZ model read on screen
- Mode checked for a wipe
- Photos copied before a refurbish flash
- Same KDZ retried once, not a cousin model
- AC or a full battery
- Other LG suites closed so they do not hold the port

| Failure | Meaning |
|---|---|
| File rejected | DLL or model |
| Early stop | Cable or port, then the same KDZ |
| Boot loop | Wrong variant, or an interrupted write |
| Data gone | The mode you confirmed |
| LGUP will not start | The PC is newer than this tool build |

The phone you may flash is the one that matches the KDZ. Account removal is not a mode in this window.

## Same KDZ, Other Suites Closed

If the flash stops, change the port and run the same file. A second model is not a retry. Close phone suites that hold the LG driver. Refurbish mode deletes data. Copy it first. A DLL that will not install on this Windows build is a PC problem. The phone can wait. Read the model string the KDZ reports before you start. Neighboring variants share a family name and not a firmware.

- Model string visible
- Mode checked for a wipe
- Other LG tools closed
- One retry, same file
- Photos already copied
